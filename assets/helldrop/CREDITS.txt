HELLDROP ASSET PACK
===================

This WAD (assets/helldrop.wad) is the Helldrop asset pack: a redistributable
art/sound/level set assembled by tools/mkwad from the Freedoom project plus
Helldrop's own override lumps. It contains NO id Software material and is
free to distribute under the terms below. Owners of an id IWAD can still pass
--wad (or drop DOOM.WAD/DOOM2.WAD in assets/) for the exact id look.

Base assets: The Freedoom Project (https://freedoom.github.io/)
Helldrop overrides (HUD reskin, etc.): the Helldrop authors.
